# Imperial visual design

The requested reference is translated into an original classical game interface: midnight blue panels, burgundy banners, gilded borders, jewel-coloured collectible illustrations, and a Roman terrace at twilight. The interface and educational rules stay in English; the Spanish historical content and both game modes are preserved.

## Original background

- Final asset: `dist/assets/imperial-terrace.png` (1536 × 1024).
- Generated with the built-in ImageGen tool, then copied into this repository.
- The supplied UI image served as visual direction. Its branding, portraits, slot reels, prizes and other commercial artwork were not copied into the project.

### Generation prompt

Use case: stylized-concept. Asset type: panoramic background illustration for an existing educational historical card game website, called Antes o Después. Create an original richly painted polished mobile-game art background inspired by classical Roman palace terraces. Wide landscape 1536x1024 composition. Deep midnight blue and lapis night sky, teal cypress trees, tall Roman marble colonnades on far left with burgundy banners bearing subtle gold laurel motifs but NO lettering, a sweeping elegant pale marble balustrade and arches on the far right, broad stone terrace and steps in foreground, a partly fallen classical column near lower right. Golden sunset rim light meeting deep blue twilight, warm amber lamps, painterly hand-painted 3D game-art depth, luxurious stylized detailed surfaces. Center of image mostly atmospheric open dark blue-purple space and a distant garden so real HTML controls placed there will remain readable; architecture frames the sides and top edges. Atmospheric very small gold dust sparks near corners, restrained, no coins or currency. No characters. No text, no logos, no watermarks, no UI, no slot machines, no numbers, no cards. The game interface will supply all headings and controls. Opaque background.

## Card art

`dist/art.js` contains the 29 original SVG illustrations. The imperial version adds jade, garnet, lapis, bronze and ivory gradients, gold borders and outlines, and layered highlights. SVG paint IDs are unique per rendered instance so several cards can safely share a page.

## Supplied class images

`dist/assets/class-people.png`, `class-events.png` and `class-time.png` preserve the exact original image bytes supplied in the conversation. `class-lexicon.jpg` is the user-specified A2 vocabulary reference. The first image supplies the 12 inventor portraits through accessible SVG viewports in `dist/photos.js`; the source bitmaps are unchanged. Inventor portraits accompany the corresponding invention illustration. All four references can be opened from the setup screen.
